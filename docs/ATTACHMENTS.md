# Reference attachments

Browse, drop or paste up to four files, 10 MiB combined. Images support PNG, JPEG, GIF and WebP. PDF and text/code references are supported, including Markdown, CSV, JSON, JSX, JavaScript, TypeScript, XML, YAML, TOML, HTML, CSS, Python, SQL and logs. Code and structured text are submitted as text/plain, matching CookieMonster's attachment normalization. They are context, not scripts to execute.

Audio, video and Office documents are not accepted by the current CookieMonster composer path. The panel explains that restriction rather than uploading an unsupported file. Model-specific processing remains CookieMonster's responsibility.

Only authenticated chat request/response limits increase to 16 MiB to accommodate base64 encoding. AE host commands keep their existing 4 MiB limit. Frame capture shares the attachment budget. Drafts clear on project changes; exact delivery deduplication includes attachment content. Retry loads complete supported attachments and rejects unavailable files.

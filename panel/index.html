Connection recovery & advanced settings

Local identities and credentials are managed automatically. Manual pairing is retained for credential recovery. Another conversation's ownership requires an explicit takeover in chat.

If authentication fails, install matching panel/plugin versions, enter a fresh single-use code above, then explicitly recover. This replaces the server credential for the same profile, retains identity, uncertain latch and durable locks, and does not reconnect. Never delete profile or bridge state to recover.

Capture & Recovery

Request a composition frame in chat for visual inspection. Keep this panel visible and stop previews first. Capture waits for a complete PNG; a timeout preserves its destination and requires reconciliation.

Timed-out scripts are never retried. Wait for AE to return, inspect the project and queue, then clear the local latch. Rebind and reconcile the durable lock in chat separately.
